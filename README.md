VIDEO EXPLICACION

Godot es una herramienta de desarrollo de videojuegos 2D y 3D, bastante simple y muy accesible
La principal funcion es el trabajo segmentado en diferentes escenas que se implementan en un nivel
de manera sencilla.

Para ello, programamos cada parte del nivel por separado como objetos unicos, al igual que haciamos en unity 
al guardar prefabs, gaurdamos un modelo de toda la visual y programacion de un objeto  a usar en el juego, de esta manera
podemos invocar varias copias de cada uno sin editar necesariamente a cada uno.

REFELEXION

Godot es un programa muy accesible y amigable, tiene la capacidad de crear complejas interaciones y escenas de un forma rapida
y funcional sin tanta logica trasera como en unity o rigor funcional de Unreal, el sistema de escenas es muy acertivo y funcional, 
ademas de brindar herramientas y accesos muy instructivos como el sistema de señales ligada a "TAGS" como se conocian en unity o el 
simple hecho de incluir codigo e informacion de cada funcionalidad basica.

Fue cuestion de un par de horas comprender el ciclo de trabajo de Godot a comparacion de otros programas, realmente toma 
todo lo bueno de Unity, como el sistema prefab y TileMaping pero dejando de lado la compleja sintaxis de C++. Es un gran programa.
